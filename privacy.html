Privacy Policy

Last updated: 2026-10-15 · gyohun-shorts

Who uses this app

gyohun-shorts is used only by the owner of a single YouTube channel, on the owner's own computer. It is not offered to the public.

What Google user data it accesses

  • YouTube Data API (scope youtube): the owner's channel information, and the owner's own videos so that it can upload Shorts, set their privacy status and scheduled publish time, and delete or make private a video the owner rejects.
  • YouTube Analytics API (scope yt-analytics.readonly): read-only statistics of the owner's own channel and videos, used to decide which topics to make next.

How the data is used, stored and shared

  • The data is used only to perform the functions above for the owner.
  • OAuth tokens and channel statistics are stored only on the owner's computer. Nothing is sent to any server operated by this app; there is none.
  • The data is not sold, shared with third parties, or used for advertising.
  • gyohun-shorts's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections or via the Google security settings page. Locally stored tokens and statistics are deleted by the owner removing them from their computer.
